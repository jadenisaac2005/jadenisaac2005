## 🚀 Flagship Projects

### [Psyche-Align](https://github.com/jadenisaac2005/psyche-align)
A multi-disciplinary simulation sandbox evaluating agentic AI behaviors against human psychological profiles and regulatory boundaries. Simulates multi-turn human-agent dialogue loops using custom user personas (e.g., highly anxious, impulse-driven) to profile cognitive framing tactics. Incorporates an analysis pipeline mapping linguistic complexity against statutory compliance constraints under the India DPDP Act and the EU AI Act.

**Stack:** Python · FastAPI · LangChain · OpenAI/Anthropic APIs · Pydantic · python-dotenv

### [Neural Network from Scratch (NumPy)](https://github.com/jadenisaac2005/nn-from-scratch)
A feedforward neural network built from scratch using only NumPy — no frameworks. Covers dense layers, ReLU/Softmax activations, cross-entropy loss, manual backpropagation, and optimizers (SGD, Momentum, Adam) with Xavier/He initialization. Benchmarked on MNIST with a paired technical report on optimization dynamics.

### [Neural Network in C++](https://github.com/jadenisaac2005/cpp-neural-network)
A modular feedforward neural network implemented from scratch in C++, featuring backpropagation, custom activation functions, and dynamic layer configuration — applied to handwritten digit classification. Compiled to WebAssembly and served via an interactive HTML Canvas frontend.

### [Rockfall Prediction System](https://github.com/jadenisaac2005/rockfall-prediction)
An AI-powered early warning system for rockfall incidents in open-pit mines, built for the **Smart India Hackathon (SIH)**. Uses an **XGBoost + Random Forest ensemble** with SMOTE oversampling to handle class imbalance, a derived interaction feature (`rainfall × slope angle`) for improved signal, and dynamic threshold tuning via F1-score search. Served via **FastAPI** with a **React** frontend for real-time risk monitoring.

**Stack:** Python · XGBoost · RandomForest · SMOTE · FastAPI · React
